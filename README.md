# PlaceHub – Student Placement Dashboard (HTML, CSS, JavaScript)

No build step or libraries. Open `login.html` in a browser (or use VS Code Live Server).

## Files
- `login.html`, `register.html`: authentication with form validation
- `dashboard.html`: stats, placement trend chart (SVG), upcoming deadlines
- `jobs.html`: search, filter and apply
- `applications.html`: status tracking and interview schedule
- `notifications.html`: interview alerts, company updates, announcements
- `profile.html`: profile management
- `css/style.css`: responsive styles with dark mode
- `js/app.js`: shared data, session handling, validation and page logic

Data is stored in the browser (localStorage). Deploy by uploading the folder to Netlify, Vercel or GitHub Pages.
